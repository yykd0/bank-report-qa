# 银行财报问答：混合检索与带出处回答

使用巨潮资讯公布的 11 家银行报告全文，构建 BM25 与 LSA 向量索引。页面对受支持的财务指标直接回答并链接到原报告的 PDF 物理页；跨公司问题逐家召回、分别取得表格证据，再比较同一指标。

## 运行

```shell
python -m venv .venv
# Windows: .venv\Scripts\activate
pip install -r requirements.txt
python download.py
python build_index.py
python evaluate.py
python summarize_evaluation.py
streamlit run app.py
```

Python 3.10 以上。下载需要访问巨潮资讯；全文索引涉及 3,472 页，耗时因机器而异。下载的 PDF 和索引保存在 `data/` 并由 `.gitignore` 排除；`.env` 也不会提交。索引使用 pickle，请不要加载不可信来源的索引文件。

页面无需 API key，也不调用大模型：采用可检查的规则，从原 PDF 表格提取并对齐指标、年份、数值和单位，生成答案并附引用。例如：

- `成都银行2024年末不良贷款率是多少？`
- `比较成都银行和中信银行2024年末不良贷款率，谁更低？`
- `宁波银行和青岛银行2024年营业收入谁更高？`（比较前统一千元和百万元）

目前支持营业收入、归母净利润、不良贷款率、拨备覆盖率、净利息收益率、资本充足率、总资产等明确指标；问题需指定公司和一个年份。关键词识别可接受“营收”“不良率”等简写。首页下拉框可指定单家公司；问题里明确的公司优先。不能可靠判断时会拒答或标明覆盖不完整。这个规则系统不是开放式问答模型。

## 构建与表格方法

- `reports.json` / `checksums.json`：报告来源、期间和文件哈希；`download.py` 下载并校验。
- `build_index.py`：按 PDF 页提取文字与表格，保存报告、公司、章节、物理页等元数据；BM25 和 TF-IDF/SVD 稠密向量用 RRF 融合。向量为 LSA，并非预训练语义嵌入。
- `table_qa.py`：查找索引中财务摘要页（前 60 页），按 PDF 坐标重建同页多年份表头与指定指标行，按列位置匹配数值。只有匹配到年份、数字和单位时才输出；截图页面中展示重建行并链接原页。这是对常见简单财务表格的改进，跨页表、扫描件、合并单元格及复杂多栏仍可能失败。
- `qa_engine.py` / `search.py`：跨公司分别检索，附回来源；金额比较前统一单位，部分公司证据缺失时不作完整比较。
- `app.py`：本地 Streamlit 页面；`evaluate.py` / `summarize_evaluation.py`：评测及可读记录。

## 评测与边界

原 10 题中，上一版严格按页面直接给出完整答案为 0/10；新版对预先核对的数值、单位、结论与引用检查为 10/10。新增两道涵盖全部 11 家银行的全景题均未完整回答：不良率题覆盖 7/11 家，营收排名题覆盖 10/11 家，均明确缺失并拒绝完整排名。另有 8 道补充题（同义问法、跨年份、跨单位和跨公司）为 8/8，8 道不支持或证据不足的拒答检查为 8/8。详见 `outputs/evaluation.md`、完整块记录 `outputs/evaluation.json`，以及保留的 `evaluation-baseline.*`。这些小样本测试不能代表任意问题上的准确率，也不是对语言模型的测试。

样本为 8 份 2024 年年报、2 份 2025 年年报及 1 份 2025 年半年报；江苏银行没有本样本的全年报告，因此不能作为 2025 年全年收入的证据。不同报告间的集团/本行口径、年度和计量单位仍需回看原文。某些题目（多指标、跨年变化、细分贷款口径、季度/半年等）主动拒答。页码是 PDF 阅读器物理页，可能不同于印刷页码；章节为规则推断。

仓库不包含下载的财报 PDF、索引或凭据。`outputs/一页结论.pdf` 和 `outputs/qa-screenshot.jpg` 可作为作业附件。
